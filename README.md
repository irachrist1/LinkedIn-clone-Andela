# LinkedIn-clone-Andela

Static HTML/CSS LinkedIn profile clone — Andela front-end exercise.

## The problem

You need to practice translating a complex layout (LinkedIn profile) into semantic HTML and CSS without a framework yet.

## What it does

Single-page LinkedIn-style profile layout in `index.html` with assets in `Assets/`.

## Install

```bash
git clone https://github.com/irachrist1/LinkedIn-clone-Andela.git && cd LinkedIn-clone-Andela
open index.html
```

## How it works

- **Layout-first HTML.** Profile header, sidebar, feed columns — CSS grid/flex practice on a real-world reference.
- **Static clone.** No backend — pure markup and styling exercise.
- **Asset-driven design.** Images and icons in `Assets/` — matches how early front-end projects are structured.
